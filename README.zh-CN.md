# xrhea

**iOS 17 越狱电池与充电插件** · [English](README.md)

Rhea（瑞亚）是土卫五，希腊神话里的众神之母、一切力量的源头；电池就是手机的力量之源。xrhea 看护的就是它：详细的电池读数、真正能停充的充电上限、看得清电去哪了的电池日志，还有从灵动岛弹出的、一眼看得懂的提醒。代码全部从头写。

Objective‑C / Logos，用 Theos 编译，适用 **roothide** 越狱。为 iOS 17 制作，**只在 iOS 17.3.1 上测试过**，其他版本可能有功能不工作。设置页有中文和英文，跟随系统语言，也可以在「关于 › 语言」里选。

## 功能

**电池信息**
- 最大容量（相对新电池）和进度条。
- 实时：状态、电量、功率、电压、电流、温度、预计（充电时是多久充满 / 充到上限，用电池时是还能用多久）。充电时的功率是充电头送进手机的功率，和 USB 数显线对得上。
- 充电器：最大功率、协商的电压电流、型号。
- 容量（实际容量、设计容量、当前电量）和循环次数。
- 需要注意的读数会标 ⚠️（电池老化、温度过高、充电器只跑 5 V、充电太慢、耗电很快），点开有处理办法；还有一页「这些数字怎么看」。

**日志**
- 24 小时电量曲线，标出充电和锁屏掉电快的时段。
- 最近 30 天的充电记录：时间、电量、充入多少、平均和最高功率、最高温度、充电器、结束方式（拔线 / 停在上限 / 充满），每次都有电量和功率曲线。
- 充电器：每个充电器的实测充电速度、用过几次，可以改名字。
- 耗电排查：锁屏待机平均每小时掉多少、各 App 耗电排行（全部 / 锁屏时，来自系统电池记录）、最近 24 小时推送重连和网络唤醒次数。推送重连偏多（常见原因是代理或 VPN）时会标出来，并给出可能的原因。
- 导出：把以上内容生成一份 Markdown 文件，可以保存，也可以直接交给 AI 分析。

**充电上限**
- 充到 60%～90% 就停。插着线时电源直接给手机供电，电池不充也不放；电量掉到你设的回落线以下才重新充。
- 充得快时会提前约 1% 停，保证不超过上限。
- 插上电源时问你「按上限停」还是「这次充满」，出门前想充满很方便；拔线后自动恢复上限。
- 定时充满：夜里先停在上限，按这个充电头记下的充电速度算好开始时间，在你设的时间前充到 100%。
- 每月提醒充满一次，让电量统计保持准确。
- 由一个 root 后台小服务执行。关掉上限、卸载插件或重启手机，都会马上恢复正常充电。

**优化**
- 页面顶部显示当前状态：正在起作用的功能和对应读数。
- 高温保护：充电时电池达到设定温度（30～50℃，推荐有线 40℃、无线 37℃）就停充，或改为间歇充电（停 3 分钟、充 3 分钟交替，平均电流约减半）；降到设定温度以下 3℃ 后恢复。
- 边充边玩直充：整机功耗 1 分钟平均高于设定值（推荐 4 W）时停止给电池充电，由电源直接供电，温度更低；负载降下来后恢复充电。电量低于 20% 时不直充。
- 后台耗电提醒：每小时查看一次系统电池记录，某个 App 连续 3 个锁屏小时占耗电超过设定比例时提醒。

**低电量模式**
- 电量低于设定值时自动开启、充到设定电量时自动关闭、锁屏时开启（解锁后关闭）、充电时开启（拔线后关闭）。
- ProMotion 机型在低电量模式下保持 120Hz 刷新率，其他省电措施不变。这部分运行在 backboardd 里，只改变屏幕读取低电量状态的结果。

**提醒**
- 从灵动岛弹出：长条样式和系统插电时那条一样（左边一句话、右边数值），也可以选短条；没有灵动岛的机型用顶部横幅。
- 充电：插电（显示充电功率，开了定时充满时显示开始和充满时间）、到点（充到你设的电量）、到上限停充、开始边充边玩直充、充满、拔线时总结这次充了多少、高温保护。
- 异常：慢充、过热降速、接触不良、插着电却不充、电池过热、低温充电。
- 用电：锁屏期间掉电快、睡前电量低、高耗电、App 后台耗电多、每周一早上的上周小结。
- 每条都有单独开关，后面有「预览」，用手机当前的数据弹一次给你看。
- 专注模式时静默，可以自己选哪几条照常提醒（默认只有过热、低温）。
- 点一下提醒打开相关页面（电池信息；每周小结打开日志）。
- 同一种提醒 30 分钟内只弹一次。

**关于页**
- 语言（跟随系统 / 中文 / English）、到 GitHub 检查新版本、反馈问题、复制问题信息（版本、机型和改过的设置）、重置所有设置。

设置在「设置 › xrhea」。

## 隐私

xrhea 只在手机上读电池自己报出来的数据和系统的电池记录，所有东西都留在手机上，不收集、不上传任何信息；唯一的联网是打开关于页时到 GitHub 查一次有没有新版本。日志导出只在你点的时候生成，只发到你选择分享的地方；里面包含哪些 App 用了电。电池和充电器的序列号不会显示、保存或导出。

## 安装

在 Sileo 或 Zebra 添加软件源 `https://oryanfang.github.io/repo/`，安装 **xrhea**。也可以在 [Releases](https://github.com/oryanfang/xrhea/releases) 下载 `.deb`。

只支持 roothide（包架构 `iphoneos-arm64e`）。rootless / rootful 需要自己改打包方式，见 [BUILDING.md](BUILDING.md)。
